# harnesses — Agent Guidance

## Project Identity

This is a **template library**, not a runnable project. It contains agent harness configurations used across the Phenotype ecosystem.

## What This Project Is

- **Purpose**: Provide configuration templates for AI agent integration with AgilePlus
- **Type**: Template library (configuration files)
- **No runtime**: There is nothing to build, test, or run

## Agent Behavior

### DO

- Read harness configurations from this directory
- Copy configurations to agent configuration directories
- Update harness documentation when AgilePlus changes

### DON'T

- Try to build or test this project
- Run `cargo test`, `npm test`, or similar
- Add runtime code or dependencies
