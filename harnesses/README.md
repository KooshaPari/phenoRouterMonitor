# harnesses — Agent Configuration Templates

## Overview

- **Type**: Template Library
- **Purpose**: Agent harness configurations for Claude Code, Codex, and Cursor
- **Contents**: Configuration templates for integrating with AgilePlus

## Structure

```
harnesses/
├── CLAUDE-CODE.md   # Claude Code harness configuration
├── CODEX.md         # Codex harness configuration
├── CURSOR.md        # Cursor harness configuration
├── README.md        # This file
├── AGENTS.md        # Agent guidance
├── .gitignore       # Git ignore patterns
└── .agileplus/     # AgilePlus worklog
```

## Contents

### CLAUDE-CODE.md

Configuration for Claude Code agent integration with AgilePlus.

### CODEX.md

Configuration for Codex agent integration with AgilePlus.

### CURSOR.md

Configuration for Cursor AI agent integration with AgilePlus.

Copy the relevant harness file to your agent configuration directory.
