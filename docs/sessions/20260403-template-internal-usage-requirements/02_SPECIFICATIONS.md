# Specifications

## Decision target
Determine the intended internal operating model for template strategy and documentation surfaces.

## Decision rules
1. Prefer one canonical landing/index surface per repo for navigation.
2. Preserve separate systems when they represent different concerns: shared layer, language layer, domain layer, control plane, registry, runtime state.
3. Treat machine-readable registries/contracts as the source of truth for automation.
4. Treat session docs and worklogs as human-oriented evidence surfaces.
