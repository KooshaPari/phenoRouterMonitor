REVIEW ARCHITECTURE
─────────────────────────────────────────────────────────────────────────────

PR Flow:
  1. Developer opens PR
  2. CodeRabbit AI review (40% weight) — auto-triggered
  3. GitHub Actions security checks:
     - CodeQL (20% weight)
     - Cargo Audit (25% weight)
     - Gitleaks/Trufflehog (10% weight)
     - Custom checks (5% weight)
  4. Branch protection validation:
     - All checks pass? ✓
     - Approval threshold (70%) met? ✓
     - No conflicts? ✓
     - Up-to-date? ✓
  5. Auto-merge (if enabled) or manual merge

Approval Thresholds:
  - Normal changes: 70%
  - Critical/security: 85%
  - Hotfixes: 50%

Critical File Patterns:
  - *.lock files
  - .github/workflows/**
  - Cargo.toml
  - review.toml
  - .coderabbit.yaml

GITHUB ACTIONS WORKFLOWS INCLUDED
─────────────────────────────────────────────────────────────────────────────

Ready-to-use templates in GITHUB_ACTIONS_WORKFLOW_TEMPLATES.md:

1. auto-format-rust.yml
   - Runs cargo fmt on Rust files
   - Commits changes back to PR
   - Posts comment about formatting

2. request-critical-review.yml
   - Detects critical file changes
   - Automatically requests code owner review
   - Posts warning comment

3. auto-merge-approved.yml
   - Merges PR when all checks pass + approval
   - Uses squash merge
   - Deletes branch after merge

4. auto-merge-dependabot.yml
   - Auto-merges Dependabot patch/minor updates
   - Requires human review for major updates

5. auto-fix-markdown.yml
   - Runs markdownlint with auto-fix
   - Commits formatting fixes

6. validate-commits.yml
   - Enforces conventional commit format
   - Blocks merge if format invalid

7. review-summary.yml
   - Generates PR summary with metrics
   - Posts checklist for reviewers

8. block-breaking-changes.yml
   - Detects breaking changes
   - Requests additional review
   - Forces documentation

9. large-pr-warning.yml
   - Warns on PRs >500 lines
   - Suggests breaking into smaller PRs

10. enforce-security-checklist.yml
    - Requires security checklist completion
    - Blocks merge if incomplete
