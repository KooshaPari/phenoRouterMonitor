Phenotype started as a mechanical keyboard company. It's becoming something much bigger — a proof that a single person, augmented by AI agents, can build and run a software organization at scale.

## The Origin

Phenotype began with custom keycap sets. GMK Arch was our first success — a design inspired by Arch Linux that resonated with the mechanical keyboard community. From there came DSS Cipher, WITF Board, and a growing catalog of products.

But the real product wasn't the keyboards. It was the **system** for building them.

## The Architecture

Phenotype is now a multi-agent ecosystem:

- **Forge** — Implementation and feature development
- **Muse** — Code review and quality assurance
- **Sage** — Research and investigation
- **Helios** — Runtime and testing specialization

Each agent has a defined role, communicates through structured protocols, and operates within clear boundaries. Together, they form a software organization that I direct rather than manually operate.

## Key Principles

**Agent-first development.** Every task starts with a spec, gets delegated to the right agent, and flows through a review pipeline. I'm the conductor, not the orchestra.

**Clean architecture.** Each crate in the Phenotype workspace is independently consumable. No tangled dependencies, no implicit coupling. Event sourcing, policy engines, state machines — all generic, all reusable.

**Design as a first-class concern.** The portfolio you're reading now, the keyboard designs, the terminal UI — everything shares a visual language. Dark backgrounds, teal accents, deliberate whitespace.

## Lessons from the Trenches

Building a one-person org with AI agents has taught me more about software engineering than years of traditional development:

1. **Specs are everything.** Vague instructions produce vague results. Precision in requirements is the highest-leverage skill.
2. **Review is non-negotiable.** Every agent's output gets reviewed. Quality compounds.
3. **Systems over solutions.** Don't solve a problem — build a system that solves it and every variant that follows.

## What's Next

The Phenotype ecosystem is expanding. More agents, more crates, more products. The mechanical keyboard business funds the research, and the research makes the business more efficient.

I'll be writing more about the technical details here — event sourcing implementations, agent coordination patterns, and the occasional keyboard design post for the enthusiasts.
